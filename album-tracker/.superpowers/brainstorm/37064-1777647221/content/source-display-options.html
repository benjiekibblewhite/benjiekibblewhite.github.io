How should we display album sources on the dashboard?

Albums come from publications like NPR, Rolling Stone, Pitchfork, etc. Each album can appear in multiple lists with different rankings.

A

Compact Badges

Carole King - Tapestry

Year: 1971

NPR #10 Rolling Stone #26

Pros

  • Compact, doesn't take much space
  • Shows key info (publication + rank)
  • Easy to scan multiple sources

Cons

  • Limited detail (no blurbs or links)
  • Might need abbreviations for long publication names
B

Detailed List

Carole King - Tapestry

Year: 1971

NPR - Rank #10
From: "The 150 Greatest Albums Made By Women"
Rolling Stone - Rank #26
From: "2023 Best Albums of All Time"

Pros

  • Shows full publication names
  • Includes list titles for context
  • Room for blurbs if needed

Cons

  • Takes more vertical space
  • Can feel verbose for albums with many sources
C

Expandable Summary

Carole King - Tapestry

Year: 1971

Pros

  • Most compact default view
  • User can see details on demand
  • Scales well for many sources

Cons

  • Requires interaction to see details
  • More complex to implement
  • User might miss source info if not expanded
D

Minimal Count

Carole King - Tapestry

Year: 1971

Featured in 2 lists

Pros

  • Simplest, cleanest look
  • Gives sense of importance (more lists = more notable)
  • No visual clutter

Cons

  • No way to see which publications
  • No ranking information
  • Least informative option
